# Extracted visual direction

The supplied logo is a transparent, high-contrast 3D security illustration. It combines a deep indigo shield, Ethereum identity, paired profile cards, neon-mint orbit lines and a vermilion warning state.

## Palette

- Ink background: `#07101f`
- Raised navy: `#0d1930`
- Shield indigo: `#2520a4`
- Electric blue: `#3658ff`
- Neon mint: `#10efb0`
- Deep green: `#078766`
- Alert vermilion: `#ff4939`
- Ice surface: `#f4f7ff`
- Cool text: `#b9c7df`
- Muted slate: `#65738e`

## Typography and hierarchy

- Display: condensed technical face (`Bahnschrift Condensed`, fallback sans-serif), 58–76px desktop, tight tracking.
- Body: humanist technical sans (`Aptos`, fallback sans-serif), 14–16px, 1.55 line height.
- Labels and evidence: monospace, 10–12px, wide tracking.

## Composition

- Dark operational command center rather than a conventional form dashboard.
- Asymmetric hero with large cropped logo orbiting behind the headline.
- Three-column workspace: procedure rail, stateful command console, evidence timeline.
- Diagonal clipping and fine grid lines echo the faceted shield.
- Mint means source-bound/continuous; red means quarantine; indigo means pending consensus.

## Components

- Rectangular controls with clipped top-right corners, 1px cool-blue borders and strong focus rings.
- One context-sensitive primary action per procedure state.
- Persistent transaction rail exposes signature, consensus, finality and readback state.
- Evidence cards show exact event position and never imply success before readback.

## Motion

- 450ms staged hero entrance.
- Slow orbit strokes around the logo; disabled under reduced-motion preferences.
- 160ms control transitions and a restrained loading rotation.

## Accessibility

- Minimum 44px targets.
- Text contrast maintained on dark surfaces.
- Status is always expressed with words, not color alone.
- Responsive layout collapses evidence below the command console without removing controls.
